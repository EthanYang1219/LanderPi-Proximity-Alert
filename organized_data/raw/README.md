# Raw data

Machine-written logs, produced automatically by ROS 2 nodes — never
hand-edited. See the `README.md` in each subfolder for column definitions:

- [`trial_logs/`](trial_logs/README.md) — per-trial motion data (`carpet.csv`, `granite.csv`)
- [`decision_logs/`](decision_logs/README.md) — per-decision avoidance data (`decision_log.csv`)
- [`scan_traces/`](scan_traces/README.md) — per-scan-tick LiDAR trace (not copied here — ~1 GB; see that folder's README for why and where it actually lives)
